# CPU 软渲染器 v1.0 范围冻结

## 冻结结论

本项目以现有图形数学模块为基础，实现一个可构建、可验证、可讲解的 CPU 简易 PBR 软渲染器。当前已建立 framebuffer、颜色/深度缓冲和渲染循环，并按日程完成 OBJ 读取、顶点着色、三角形覆盖、透视正确插值、深度测试、基础面剔除、纹理/UV 采样、法线/切线数据、Lambert 漫反射及曝光/色调映射；GGX BRDF 仍留在后续阶段。

v1.0 明确不做阴影、抗锯齿和次表面散射。新增功能如果不服务于既定的 OBJ → 顶点变换 → 三角形光栅化 → 纹理/法线 → 简化 PBR 路径，应记录为后续候选，不进入当前版本。

## 当前骨架

| 模块 | 输入 | 输出 | 职责边界 |
| --- | --- | --- | --- |
| `Framebuffer` | 宽高、RGBA 颜色、`[0, 1]` 深度 | 行主序颜色缓冲与深度缓冲 | 分配、清屏、安全读写、严格 `Less` 深度测试和原子片元提交；不执行混合 |
| `ObjLoader` | OBJ 文件或输入流 | 位置、UV、法线与三角面索引 | 解析、索引换算、扇形三角化和结构化错误定位；不生成缺失属性 |
| `VertexStage` | OBJ 网格、M/V/P 矩阵、视口与法线回退选项 | 顶点变换、`1/w`、UV、世界法线/切线/手性与屏幕三角形 | 装配、属性生成/变换和保守裁剪分类；不执行几何裁剪或光栅化 |
| `Rasterizer` | 完全位于裁剪体内的屏幕三角形、framebuffer 尺寸、剔除选项 | 像素坐标、线性/透视重心权重、`1/w` 和屏幕深度 | 覆盖、插值和基础面剔除；不执行几何裁剪、深度测试或着色 |
| `Texture2D` | PPM 文件/流、UV 与采样状态 | 顶部起始行主序 RGBA、最近邻颜色 | P3/P6 解析、归一化、Clamp/Repeat 寻址；不解码 PNG/JPEG 或生成 mipmap |
| `Shading` | 线性反照率、世界法线、方向光、HDR 颜色与曝光档位 | Lambert 辐亮度、曝光/色调映射结果与 sRGB 显示颜色 | 直接漫反射和显示变换；不执行 GGX、阴影或图像写出 |
| `SoftwareRenderer` | `RendererConfig`、帧数、帧回调 | 已清屏的 `FrameContext`、完成帧计数 | 驱动帧生命周期；不解析场景、不光栅化、不着色 |
| `soft_renderer` | 4×3 固定配置与 3 帧回调 | 数值基准与 PASS/FAIL 退出码 | 骨架验收；不作为最终图像演示程序 |
| `obj_loader_acceptance` | 固定 OBJ 样例与内存输入 | 数据/索引基准与 PASS/FAIL 退出码 | OBJ 读取验收；不执行顶点变换 |
| `vertex_stage_acceptance` | 三组三角面与固定相机/视口 | 坐标、裁剪分类与 PASS/FAIL 退出码 | 顶点阶段验收；不填充像素 |
| `triangle_rasterizer_acceptance` | 固定屏幕三角形与属性 | 覆盖、重心/透视权重与 PASS/FAIL 退出码 | 光栅化验收；不写 framebuffer |
| `depth_buffer_acceptance` | 重叠近远三角形、颜色与剔除选项 | 遮挡、顺序无关、面剔除与 PASS/FAIL 退出码 | 深度阶段验收；不执行纹理或光照 |
| `texture_sampling_acceptance` | P3/P6 基准纹理、UV、透视三角形 | 解码、寻址、采样、片元写入与 PASS/FAIL 退出码 | 纹理阶段验收；不执行过滤或光照 |
| `surface_attributes_acceptance` | 标准/镜像/退化 UV、源/缺失法线与非均匀/反射缩放 | 世界法线、切线、手性、插值 TBN 与 PASS/FAIL 退出码 | 表面属性验收；不执行法线贴图或光照 |
| `diffuse_exposure_acceptance` | 固定反照率/方向光/HDR 颜色与纹理三角形 | Lambert、曝光、Reinhard、sRGB 和完整片元路径基准 | 漫反射与显示变换验收；不执行 GGX |

单帧顺序固定为：

1. 清空 RGBA 颜色缓冲。
2. 清空深度缓冲。
3. 调用一次帧回调，并传入单调递增的帧序号和 framebuffer。
4. 回调成功后累计完成帧数；回调抛出异常时不计为完成帧。

## 数据口径

- 像素坐标原点位于左上角，X 向右、Y 向下。
- 缓冲采用行主序，索引为 `y * width + x`。
- 颜色使用有限的双精度 RGBA，不在 framebuffer 层截断 HDR 数值。
- 深度使用 `[0, 1]`，越小越靠近相机；清屏值为 `1.0`，深度测试采用严格 `incoming < stored`。
- `depthTest` 只查询且不修改缓冲；`writeFragment` 仅在测试通过时原子更新颜色和深度，失败时两者都保持不变。
- framebuffer 宽高必须非零，且像素数乘法不得溢出。
- 越界坐标、非法深度、非有限颜色和递归帧调用均立即报错。
- OBJ 面索引统一转为零基下标，负索引相对当前数据池解析，缺省 UV/法线使用哨兵值保留。
- OBJ 面顶点接受 `v`、`v/vt`、`v//vn`、`v/vt/vn` 四种格式，三个以上顶点的面按三角扇拆分。
- 非法数字、不完整格式、零索引、越界引用和空顶点数据立即抛出 `ObjParseError`，并提供来源、行号和原因。
- 顶点阶段保留 OBJ 角点索引，输出世界、观察、裁剪、NDC、屏幕坐标和 `reciprocalW = 1 / clip.w`。
- 三角形裁剪状态分为完全位于裁剪体内、需要后续裁剪、完全位于同一裁剪平面外；本阶段不改变拓扑。
- 三角形覆盖在 `(x + 0.5, y + 0.5)` 像素中心采样，以 top-left 规则保证相邻三角形的共享边只归属一侧。
- 包围盒裁剪到 framebuffer 范围并使用右开上界；退化三角形和完全在裁剪体外的三角形不产生样本。
- 屏幕深度按线性重心坐标插值；普通顶点属性使用归一化的 `barycentric[i] * reciprocalW[i]` 权重进行透视正确插值。
- `RequiresClipping` 三角形在几何裁剪完成前不得光栅化，防止跨越无效齐次区域。
- 默认关闭面剔除；启用时可选择前面或背面，并可配置顺时针/逆时针正面。左上原点屏幕坐标默认顺时针为正面。
- 纹理数据按顶部到下部、从左到右的行主序存储，PPM RGB 通道按 `maxValue` 归一化到 `[0,1]`，Alpha 固定为 `1.0`。
- PPM 加载层保留归一化通道数值；颜色纹理参与光照前按 sRGB 解码为线性反照率。
- PPM 加载支持 ASCII `P3` 和二进制 `P6`，通道最大值范围为 `[1,65535]`；16 位 P6 按网络序读取。
- UV 默认采用左下原点，最近邻索引为 `floor(addressed * extent)`，Clamp 下的 `1.0` 固定映射到最后一个 texel。
- Clamp 将 UV 限制到 `[0,1]`，Repeat 使用小数部分处理正负坐标；也可切换为顶部 UV 原点。
- 纹理查询必须使用 `RasterSample` 的透视正确权重插值 UV，再与样本深度一起提交 framebuffer。
- 顶点阶段复制存在的 OBJ UV，以逆转置法线矩阵生成单位世界法线，并以模型矩阵线性部分变换切线方向。
- 缺失源法线默认回退为每三角形几何法线；可关闭回退，且退化几何不会伪造法线。
- 切线和副切线由三角形位置边与 UV 导数计算，切线按每角点法线正交化；输出 `tangentSign` 用于重建副切线。
- 镜像 UV 和负行列式模型变换会翻转 `tangentSign`；UV 缺失、UV 导数退化或切线平行法线时输出无切线状态。
- 片元阶段对法线、切线和手性做透视正确插值，归一化后使用 `buildTBN` 重新正交化；不直接插值 TBN 矩阵。
- 方向光的 `directionToLight` 从表面指向光源；法线与光照方向在求点积前归一化，负的 `N·L` 夹到零。
- Lambert 直接漫反射在线性空间计算：`albedo × radiance × max(N·L, 0) / π`；反照率位于 `[0,1]`，光源辐亮度非负。
- EV 曝光乘数为 `2^exposureStops`；HDR 颜色必须先曝光，再用逐通道 Reinhard `c / (1 + c)` 压缩。
- 显示颜色在色调映射后执行线性到 sRGB 编码；framebuffer 本身不隐式转换颜色空间或截断 HDR。

## 明确排除

| 排除项 | 冻结理由 |
| --- | --- |
| 阴影 | 需要额外的可见性 Pass、阴影贴图与偏移策略，不属于简易直接光基线 |
| 抗锯齿 | 会引入多采样、覆盖率或后处理路径，超出单样本 framebuffer 目标 |
| 次表面散射 | 需要材质扩散模型、厚度或屏幕空间近似，超出简化 PBR 范围 |

## 常见失败点

- 宽高为零或 `width * height` 溢出，导致无效分配。
- 把列主序数学矩阵约定误套到行主序像素缓冲索引。
- 忘记逐帧清理颜色或深度，产生上一帧残留。
- 混用 NDC `[-1, 1]` 与 framebuffer 深度 `[0, 1]`。
- 回调异常后仍增加帧计数，导致运行状态与实际输出不一致。
- 把 OBJ 的一基索引直接当作容器下标，或没有按当前位置解析负索引。
- 将缺省 UV/法线误当作索引零，导致合法的 `v`、`v/vt`、`v//vn` 面格式混淆。
- 在齐次裁剪前丢弃 `clip.w`，使后续透视正确插值失去 `1/w`。
- 仅因三个顶点都在裁剪体外就剔除三角形；只有三点位于同一裁剪平面外才可直接剔除。
- 共享边两侧都使用闭合判断，导致同一像素被重复覆盖；应统一使用 top-left 规则。
- 直接用屏幕空间重心坐标插值 UV/法线等属性，导致透视缩短区域出现明显形变。
- 对 `RequiresClipping` 三角形直接做屏幕包围盒光栅化，导致相机后方或跨近平面的无效片元。
- 深度测试通过后分别调用 `setColor` 和 `setDepth`，中途异常会留下颜色/深度不一致；应使用原子片元写入。
- 使用 `<=` 而非严格 `<` 导致等深片元依赖提交顺序，破坏固定基准的确定性。
- 忽略屏幕 Y 轴向下的约定，导致顺/逆时针正面判断与背面剔除结果颠倒。
- 把 P6 二进制像素继续按文本 token 读取，或忽略 16 位通道的大端字节序，导致颜色错位。
- 忘记翻转顶部起始纹理行与左下 UV 原点之间的 V 轴，导致贴图上下颠倒。
- 对 Clamp 边界 `u/v = 1` 直接计算 `extent` 下标，导致越界；边界必须落到最后一个 texel。
- 使用屏幕空间线性 UV 而非透视正确权重，导致远近跨度大的三角形出现纹理游移。
- 用模型矩阵直接变换法线，导致非均匀缩放后法线不再与切线垂直；法线必须使用逆转置矩阵。
- 只根据 UV 行列式保存切线符号而忽略反射模型变换，导致负缩放后副切线方向错误。
- 为缺失或退化 UV 随意选择一条切线，隐藏无效数据并使法线贴图方向在三角形间跳变。
- 直接透视插值单位法线/切线后不归一化和正交化，导致 TBN 缩放、偏斜及法线贴图失真。
- 直接用 sRGB 纹理通道计算光照，导致中间调过暗；颜色纹理必须先解码到线性空间。
- 忘记 Lambert BRDF 的 `1/π`，或未归一化法线/光照方向，导致亮度随向量长度变化。
- 把光源传播方向误当作表面到光源方向，导致正面被当作背光而归零。
- 在曝光前色调映射、色调映射前截断 HDR，或把 HDR 值直接当显示颜色，都会破坏曝光响应。

## 固定验收基准

| 检查项 | 期望值 |
| --- | --- |
| framebuffer 尺寸 | `4 × 3`，共 `12` 像素 |
| 渲染循环 | 完成 `3` 帧，帧序号依次为 `0, 1, 2` |
| 清屏 | 每帧回调开始时全部像素恢复指定颜色，深度恢复 `1.0` |
| 最后一帧写入 | `(2, 1)` 为 RGBA `(0.8, 0.2, 0.1, 1.0)`，深度 `0.25` |
| 防御检查 | 非法尺寸、深度与越界坐标均被拒绝 |
| OBJ 固定样例 | `4` 个位置、`3` 个 UV、`1` 个法线、`2` 个三角面 |
| OBJ 格式覆盖 | 四种面索引格式、位置/UV/法线正负索引、缺省属性和多边形三角化 |
| OBJ 防御检查 | 非法数字、不完整格式、零/越界索引、空顶点数据与文件打开失败均被拒绝 |
| OBJ 异常定位 | `ObjParseError` 的来源、行号、原因和组合消息一致 |
| 顶点固定基准 | 首顶点屏幕坐标 `(400, 360, 0.8889)`，`clip.w = 5`，`1/w = 0.2` |
| 三角形裁剪分类 | 完全可见、需要裁剪、完全在右裁剪平面外各 `1` 个 |
| 顶点阶段防御检查 | 位置/UV/法线越界索引、非法视口和零 `clip.w` 均被拒绝 |
| 三角形覆盖 | `(1,1)-(5,1)-(1,5)` 在像素中心覆盖 `6` 个样本；正反绕序结果一致 |
| 共享边规则 | 两个三角形无重复、无裂缝地覆盖完整 `4 × 4` 区域，共 `16` 个样本 |
| 重心与透视插值 | 首样本线性权重 `(0.75, 0.125, 0.125)`，透视权重 `(8/9, 2/27, 1/27)` |
| 光栅化防御检查 | 零尺寸、非有限顶点、非正 `1/w` 和未裁剪三角形均被拒绝；退化三角形无覆盖 |
| 深度比较 | 清屏深度 `1.0`；近片元 `0.25` 覆盖远片元 `0.75`，等深和更远片元均被拒绝 |
| 遮挡顺序无关 | “远→近”与“近→远”提交后，完整颜色和深度缓冲逐像素一致 |
| 原子片元写入 | 通过时同时更新颜色/深度；等深、远端或非法片元不改变任一缓冲 |
| 基础面剔除 | 默认顺时针正面可通过背面剔除，逆时针背面被剔除；正面约定可切换 |
| PPM 加载 | `2 × 2` P3 基准与 P6 8/16 位内存基准正确归一化；注释、截断、非法尺寸/通道均有保护 |
| UV 最近邻 | 左下四象限依次采样蓝/白/红/绿，Clamp、Repeat 与顶部原点结果固定 |
| 透视纹理 | 屏幕样本 `(3,1)` 的 UV 为 `(5/26, 1/26)`，采样蓝色并以深度 `0.5` 写入 framebuffer |
| 纹理防御检查 | 文件缺失、非法格式、越界 texel、非有限 UV 和纹理数据尺寸不匹配均被拒绝 |
| 非均匀缩放表面基 | 首角点世界法线 `(-1,0,4)/√17`、世界切线 `(4,0,1)/√17`，二者点积为 `0` |
| 法线回退 | 无 `vn` 三角形的三个角点均生成几何法线；关闭选项后保持无效状态 |
| 切线手性 | 标准 UV 为 `+1`，镜像 UV 为 `-1`，X 轴负缩放将标准 UV 的世界手性翻转为 `-1` |
| 退化属性 | 无 UV 时保留法线但无切线；零面积 UV 保留 UV/法线但无切线 |
| 插值 TBN | 透视插值后重建的 TBN 满足 `T·N = B·N = 0`、行列式 `1`，切线空间 `+Z` 映射到插值世界法线 |
| 表面属性防御检查 | 零法线、非有限 UV 和奇异法线矩阵均被拒绝 |
| Lambert 正面基准 | 反照率 `(0.8,0.4,0.2)`、正面入射和辐亮度 `(π,2π,0.5π)` 得到 `(0.8,0.8,0.1)` |
| Lambert 角度基准 | 60° 入射得到正面结果的一半；背光入射得到零 |
| 曝光与 Reinhard | HDR `(0.5,1,3)` 在 `+1 EV` 后为 `(1,2,6)`，色调映射后为 `(0.5,2/3,6/7)` |
| sRGB 转换 | 固定阈值/中间调/白色解码值正确，线性段与幂函数段均可往返 |
| 漫反射片元路径 | 透视插值 UV/法线后执行纹理采样、sRGB 解码、Lambert、曝光、色调映射并以深度 `0.5` 写入 framebuffer |
| 光照防御检查 | 越界反照率、负辐亮度/颜色、零方向、非有限曝光、曝光溢出与非法 Alpha 均被拒绝 |
| 验收标记 | 输出 `软渲染器骨架验收: PASS`，进程退出码为 `0` |
