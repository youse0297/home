# CPU 软渲染器 v1.0 范围冻结

## 冻结结论

本项目以现有图形数学模块为基础，实现一个可构建、可验证、可讲解的 CPU 简易 PBR 软渲染器。当前已建立 framebuffer、颜色/深度缓冲和渲染循环，并按日程完成 OBJ 顶点数据读取；光栅化、纹理与 BRDF 仍留在后续阶段。

v1.0 明确不做阴影、抗锯齿和次表面散射。新增功能如果不服务于既定的 OBJ → 顶点变换 → 三角形光栅化 → 纹理/法线 → 简化 PBR 路径，应记录为后续候选，不进入当前版本。

## 当前骨架

| 模块 | 输入 | 输出 | 职责边界 |
| --- | --- | --- | --- |
| `Framebuffer` | 宽高、RGBA 颜色、`[0, 1]` 深度 | 行主序颜色缓冲与深度缓冲 | 分配、缩放、清屏、安全读写；不执行深度测试或混合 |
| `ObjLoader` | OBJ 文件或输入流 | 位置、UV、法线与三角面索引 | 解析、索引换算、扇形三角化和结构化错误定位；不生成缺失属性 |
| `SoftwareRenderer` | `RendererConfig`、帧数、帧回调 | 已清屏的 `FrameContext`、完成帧计数 | 驱动帧生命周期；不解析场景、不光栅化、不着色 |
| `soft_renderer` | 4×3 固定配置与 3 帧回调 | 数值基准与 PASS/FAIL 退出码 | 骨架验收；不作为最终图像演示程序 |
| `obj_loader_acceptance` | 固定 OBJ 样例与内存输入 | 数据/索引基准与 PASS/FAIL 退出码 | OBJ 读取验收；不执行顶点变换 |

单帧顺序固定为：

1. 清空 RGBA 颜色缓冲。
2. 清空深度缓冲。
3. 调用一次帧回调，并传入单调递增的帧序号和 framebuffer。
4. 回调成功后累计完成帧数；回调抛出异常时不计为完成帧。

## 数据口径

- 像素坐标原点位于左上角，X 向右、Y 向下。
- 缓冲采用行主序，索引为 `y * width + x`。
- 颜色使用有限的双精度 RGBA，不在 framebuffer 层截断 HDR 数值。
- 深度使用 `[0, 1]`；当前只存储和清理，比较函数留到“深度缓冲”任务实现。
- framebuffer 宽高必须非零，且像素数乘法不得溢出。
- 越界坐标、非法深度、非有限颜色和递归帧调用均立即报错。
- OBJ 面索引统一转为零基下标，负索引相对当前数据池解析，缺省 UV/法线使用哨兵值保留。
- OBJ 面顶点接受 `v`、`v/vt`、`v//vn`、`v/vt/vn` 四种格式，三个以上顶点的面按三角扇拆分。
- 非法数字、不完整格式、零索引、越界引用和空顶点数据立即抛出 `ObjParseError`，并提供来源、行号和原因。

## v1.0 纳入范围

按日程顺序推进：

1. **已完成：** OBJ `v/vt/vn` 读取、三角面索引和异常处理。
2. MVP 顶点阶段与屏幕空间三角形输出。
3. 包围盒、边函数、重心坐标和透视正确插值。
4. 深度测试、遮挡顺序无关和基础背面剔除。
5. 纹理加载、UV 最近邻采样、法线与切线数据。
6. Lambert、曝光/色调映射、简化 GGX 和金属粗糙度工作流。
7. 三组材质回归、构建说明、原理文档和发布验收。

## 明确排除

| 排除项 | 冻结理由 |
| --- | --- |
| 阴影 | 需要额外的可见性 Pass、阴影贴图与偏移策略，不属于简易直接光基线 |
| 抗锯齿 | 会引入多采样、覆盖率或后处理路径，超出单样本 framebuffer 目标 |
| 次表面散射 | 需要材质扩散模型、厚度或屏幕空间近似，超出简化 PBR 范围 |

## 常见失败点

- 宽高为零或 `width * height` 溢出，导致无效分配。
- 把列主序数学矩阵约定误套到行主序像素缓冲索引。
- 忘记逐帧清理颜色或深度，产生上一帧残留。
- 混用 NDC `[-1, 1]` 与 framebuffer 深度 `[0, 1]`。
- 回调异常后仍增加帧计数，导致运行状态与实际输出不一致。
- 把 OBJ 的一基索引直接当作容器下标，或没有按当前位置解析负索引。
- 将缺省 UV/法线误当作索引零，导致合法的 `v`、`v/vt`、`v//vn` 面格式混淆。

## 固定验收基准

| 检查项 | 期望值 |
| --- | --- |
| framebuffer 尺寸 | `4 × 3`，共 `12` 像素 |
| 渲染循环 | 完成 `3` 帧，帧序号依次为 `0, 1, 2` |
| 清屏 | 每帧回调开始时全部像素恢复指定颜色，深度恢复 `1.0` |
| 最后一帧写入 | `(2, 1)` 为 RGBA `(0.8, 0.2, 0.1, 1.0)`，深度 `0.25` |
| 防御检查 | 非法尺寸、深度与越界坐标均被拒绝 |
| OBJ 固定样例 | `4` 个位置、`3` 个 UV、`1` 个法线、`2` 个三角面 |
| OBJ 格式覆盖 | 四种面索引格式、位置/UV/法线正负索引、缺省属性和多边形三角化 |
| OBJ 防御检查 | 非法数字、不完整格式、零/越界索引、空顶点数据与文件打开失败均被拒绝 |
| OBJ 异常定位 | `ObjParseError` 的来源、行号、原因和组合消息一致 |
| 验收标记 | 输出 `软渲染器骨架验收: PASS`，进程退出码为 `0` |
