## 建议首批作品集结构

1. CPU 软渲染器：一张高清最终图、一张管线图、一张关键算法图、构建链接和 60 秒视频。
2. HLSL 材质源码库：模块架构、六个运行效果、验证数据、可下载 ZIP 和三分钟讲解。
3. Unity 技术分析：贴图压缩、LOD、BasePass 三页作为过程证据，等 Editor 和 RenderDoc 证据齐全后再提升为完整项目。
4. 赛博风格化后处理：当前仅保留位置，不填任何占位成果数字。
