## 简历精简版

### C++17 CPU 软渲染器

`C++17 / CMake / OBJ / 光栅化 / PBR / 自动化测试`

- 基于 C++17 构建从 OBJ 到 P6 RGB8 图像的 CPU 软渲染管线，贯通 MVP 变换、top-left 光栅化、透视正确插值、深度与纹理采样，并实现 Lambert 和 GGX 金属粗糙度直接光。
- 建立 12 项 CTest 自动验收，以 `96×32` 三材质基准图、`1872` 个材质覆盖像素及 FNV-1a64 checksum 固定输出，当前发布门禁 `12/12` 通过。

### Unity URP HLSL 材质源码库 v1.0

`Unity 2022.3 / URP 14 / HLSL / GGX / 材质系统 / 自动化验证`

- 面向 Unity `2022.3.62f3c1`、URP `14.0.12` 拆分并封装 `18` 个 Renderer HLSL 功能模块，以统一材质接口组织采样、PBR 输入、GGX 光照、顶点变形、各向异性和透明折射，发布包包含 `19` 个 HLSL 文件、`74` 个公共符号。
- 建立空工程迁移与确定性发布流程，完成 `18/18` 个专项验证器、`116` 项源码结构检查，并以 Windows SDK `fxc /WX /Ges` 实现 smoke shader 零警告编译。

### Unity URP 材质与管线分析基线

- 建立覆盖 Metallic、Roughness、Normal Scale 的 `11` 组参数边界样例，以及 `10` 档 BasePass 表面/光照拆解视图；离线回归中最终光照分量加法误差为 `0`。
- 为 `64×64` 全 mip 纹理建立格式字节基准：BC1 相对 RGBA32 节省 `87.4%`，BC5/BC7 节省 `74.9%`；该结果仅表示固定尺寸下的格式字节差异，不代表项目实测总显存降幅。
- 固定 High `0.60`、Medium `0.25`、Low `0.05` 三档 LOD 阈值，`4/4` 个静态切换样本落入预期档位；该结果不等同于运行时 FPS 提升。
