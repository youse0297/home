# 待补素材放置说明

建议按下列目录保存后续素材，并在文件名中保留项目、内容、版本和日期。

| 目录 | 文件名示例 | 必填信息 |
| --- | --- | --- |
| `简历` | `简历_渲染技术美术_姓名_v20260907.pdf` | 目标岗位、版本日期 |
| `岗位JD` | `公司_岗位_20260907.md` | 原始链接、抓取日期、截止日 |
| `运行截图` | `HLSL材质库_各向异性_运行图_v1.0.png` | Unity 版本、场景、质量档、是否运行截图 |
| `演示视频` | `CPU软渲染器_60秒演示_v1.0.mp4` | 编码、分辨率、时长、字幕状态 |
| `量化数据` | `HLSL性能_测试环境_v1.0.csv` | 硬件、分辨率、样本数、统计方法 |
| `架构图` | `HLSL模块依赖_v1.0.png` | 版本、模块范围、图例 |
| `投递回执` | `公司_岗位_简历版本_投递日期.md` | 渠道、状态、跟进日期 |
| `讲稿` | `CPU软渲染器_三分钟讲稿_v1.0.md` | 目标、架构、难点、取舍、结果 |

不要在公共仓库中保存包含电话、证件号、家庭住址或未公开招聘联系人信息的文件。带个人信息的简历和投递回执应保存在私有副本中，本目录只维护脱敏版本或索引。
