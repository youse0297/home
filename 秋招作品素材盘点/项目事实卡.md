## C++17 CPU 软渲染器

**一句话定位**

使用 C++17 实现从 OBJ 数据到 P6 图像输出的 CPU 渲染管线，用固定数值和图像校验建立可重复发布门禁。

**可确认事实**

- 实现向量、矩阵、MVP、齐次除法、视口映射、逆转置法线矩阵和 TBN 空间转换。
- 支持 OBJ `v/vt/vn`、正负索引、三角化、异常输入、顶点装配和保守裁剪分类。
- 实现包围盒光栅化、边函数、top-left 覆盖、透视正确插值、深度测试和面剔除。
- 支持 PPM P3/P6 纹理、Clamp/Repeat 最近邻采样、sRGB 解码、法线贴图和 ORM 金属粗糙度工作流。
- 实现 Lambert、GGX NDF、Smith 遮蔽、Schlick Fresnel、曝光、Reinhard 和 sRGB 编码。
- 发布验收包含 12 项 CTest；固定图像为 96×32，材质覆盖 1872 像素，FNV-1a64 为 `0x6e50ef105c6d04c`。

**可改写为简历的草稿**

- 基于 C++17 搭建 CPU 软渲染管线，贯通 OBJ 解析、MVP、top-left 光栅化、透视正确插值、深度和纹理采样，并实现 Lambert 与 GGX 金属粗糙度直接光。
- 为关键数值和图像输出建立 12 项自动验收，通过代表色、覆盖像素、深度和整图 checksum 固定发布结果。

## Unity URP HLSL 材质源码库 v1.0

**一句话定位**

面向 Unity `2022.3.62f3c1` 与 URP `14.0.12` 的 Renderer HLSL 源码库，将采样、材质、BRDF、光照、顶点变形和效果模块组织成可迁移发布包。

**可确认事实**

- 18 个功能模块与一个聚合头，共 19 个 HLSL 文件、74 个公共符号。
- 覆盖向量与采样、PBR 输入、GGX、顶点位移、波浪风摆、多层法线、程序遮罩、边缘磨损、积雪、各向异性、透明折射、光照和统一材质接口。
- 18/18 专项验证器与 116 项源码结构检查通过。
- 在两文件空 Unity 工程骨架中完成解包、逐文件 SHA-256、include 闭包和迁移后 smoke shader 编译。
- Windows SDK `fxc` 使用 `ps_5_0`、`/WX /Ges` 编译，退出码 0，warning 数 0。
- 确定性 ZIP 的 SHA-256 为 `70a8abf77aef7de6bb1750deae824de961493f3aed2f099daaa65653f5236990`。

**可改写为简历的草稿**

- 面向 Unity URP 拆分并封装 18 个 Renderer HLSL 功能模块，以统一材质接口组织采样、表面扩展、GGX 光照、各向异性和透明折射调用边界。
- 建立空工程迁移和确定性发布流程，聚合 18 个验证器与 116 项结构检查，并以 `fxc /WX /Ges` 完成零警告 smoke 编译。

## Unity URP 材质与管线分析基线

**一句话定位**

通过参数矩阵、压缩格式、LOD 策略和 BasePass 分项输出建立 Unity 材质实验室的离线验证基线。

**可确认事实**

- 材质参数边界固定 11 个样例，覆盖 Metallic、Roughness 和 Normal Scale。
- 64×64 全 mip 字节基准中，BC1 相对 RGBA32 节省 87.4%，BC5 和 BC7 节省 74.9%。
- LOD 阈值固定为 High `0.60`、Medium `0.25`、Low `0.05`，四个固定样本均落到预期档位。
- BasePass 离线板包含 10 档表面与光照视图，`FinalLit = DirectDiffuse + DirectSpecular + IndirectDiffuse` 的误差为 0。
- 六模块材质展板的静态契约和参考布局通过，但没有当前许可证环境下的 Unity 运行截图。
