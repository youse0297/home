## 使用顺序

1. 先看 [缺口看板](缺口看板.md)，完成 P0 后再生成对外链接。
2. 用 [项目事实卡](项目事实卡.md) 写简历条目，不扩大个人贡献或验证范围。
3. 依据真实岗位 JD 更新 [岗位关键词映射](岗位关键词映射.md)，不要为命中关键词编造经验。
4. 将新截图、视频和测试数据放入 `待补素材` 指定目录，再更新素材清单。
5. 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\秋招作品素材盘点\ValidateMaterials.ps1`，确认素材文件、哈希和报告口径一致。
